# Scope

PedNStream is a Python applicaiton for creating traffic dynamics simulations for crowd management. With PedNStream, researchers can create and analyse traffic scenarios of pedestrians, and evluate the performance of different crowd management strategies and identify potential bottlenecks. The application provides a Python interface for creating and running simulations, as well as visualizing the results. In the future, we plan to proide a prompt-based interface for creating simulations, allowing users to easily specify the parameters of their simulations using natural language prompts powered by large language models.

## Features

The development of PedNStream aims to provide a comprehensive tool for simulating and analyzing pedestrian traffic dynamics. The key planned features of PedNStream include:

- Create simulations with various crowd management strategies.
- Identify bottlenecks in transportation networks by analyzing traffic scenarios.
- Visualize simulation results once simulations have been completed to gain insights into pedestrian traffic dynamics.
- Design traffic scenarios with the assistance of a dedicated AI agent.
- Automatic generation of simulation configurations with the help of large language models using principle of agentic AI.

..info:: Future Work

   The development of PedNStream is an ongoing process, and we are continuously working on adding new features and improving the existing ones. We welcome contributions from the community to help us make PedNStream a powerful tool for simulating and analyzing pedestrian traffic dynamics.
